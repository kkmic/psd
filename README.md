# Animation and handling using CMSIS DSP Python library wrapper
This is a preliminary project for studying how to use ARM-CMSIS DSP library for signal handling.
- `cmsis.test.py` uses self generated signal for Complex DFFT and animation
- `picoscope.py` uses a single frame file for analysis
- `bulkscope.py` uses the whole directory of 64 frames - output of PicoScope software for generating DFFT and Power Spectral Density animation.
